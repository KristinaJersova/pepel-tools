# pepel-tools

Редакторы для игры «Пепел после Тишины» — открыть: https://kristinajersova.github.io/pepel-tools/

- `world-editor.html` — редактор мира
- `hero-editor.html` — редактор героев
- `maps/start.tmj`, `art/maps/start.png` — начальная зона

Копия из основного (закрытого) репозитория игры, папка `tools/`. Правки делаются там и переносятся сюда.
